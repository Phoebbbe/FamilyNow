# FamilyNow

> 年轻人的合租生活管家——让账目更清楚、分工更公平、沟通更温暖。

FamilyNow 是一个面向年轻合租群体的生活协作工具，集中管理费用 AA、清洁值日、公共物品、室友公约和日常留言，帮助室友减少因为信息不同步、责任不清和沟通困难产生的矛盾。

- [打开 FamilyNow Demo](./FamilyNow.html)
- 直接双击 `FamilyNow.html` 也可以在浏览器中运行

## 项目背景

年轻人合租时经常遇到以下问题：

- 房租、水电、网络费和公共采购的分摊不透明
- 清洁任务依赖群聊提醒，容易遗漏或重复安排
- 纸巾、洗衣液等公共物品用完后无人及时补充
- 室友之间缺少明确、可共同确认的生活规则
- 有些问题不方便当面提出，长期积累后容易引发冲突

FamilyNow 将这些分散在群聊、备忘录和口头沟通中的事务放进一个统一空间，让每个人随时知道“钱该怎么算、事情谁来做、什么需要补、大家约定了什么”。

## 产品目标

FamilyNow 希望建立一种低压力的合租协作方式：

1. 让共同账目可追溯、可结算。
2. 让公共责任明确且公平轮换。
3. 让物品消耗及时被看见。
4. 让共同规则形成真实共识。
5. 让难开口的问题也能被温和表达。

## 核心功能

### 1. 家的此刻

首页集中展示当前合租屋最重要的信息：

- 本月共同支出与个人净余额
- 本周值日完成进度
- 待补货物品数量
- 室友公约确认进度
- 接下来要完成的生活事项
- 最新暖心留言

用户进入页面后无需翻找，就能快速了解家里的当前状态。

### 2. 费用 AA

- 记录费用名称、金额、付款人和费用分类
- 自由选择参与分摊的室友
- 自动计算人均金额
- 汇总每位成员的应收、应付和净余额
- 根据余额生成建议结算路径
- 新增费用后实时更新首页和账本统计

金额计算的目标是始终保证账目守恒：所有成员净余额之和应为零，每笔分摊之和应等于费用总额。

### 3. 清洁值日

- 查看一周清洁排班
- 展示日期、任务、负责人和完成状态
- 一键标记任务完成
- 自动更新本周完成进度
- 为后续的周期轮换、换班和逾期提醒预留扩展空间

### 4. 公共物品

- 统一登记洗衣液、抽纸、垃圾袋等公共物品
- 记录当前数量、单位和补货阈值
- 自动判断“充足”“快没了”和“已用完”状态
- 支持快速增加或减少库存
- 单独筛选待补货物品
- 库存变化后实时更新首页提醒

### 5. 暖心留言板

留言板用于承接合租生活中不适合在群聊里直接表达的内容。

- 支持公开身份留言
- 支持匿名纸条，匿名时不展示成员姓名
- 提供“想说谢谢”“一个小建议”“需要帮忙”等表达提示
- 支持“温暖”和“收到”轻量回应
- 使用中性、友好的提示语降低沟通压力
- 明确匿名边界：尊重留言内容，不追问匿名者身份

这个模块不仅处理问题，也鼓励成员表达感谢、认可彼此的付出。

### 6. 室友公约

- 集中展示正在生效的生活公约
- 按作息、访客、公共物品等类别组织内容
- 展示每条公约的成员确认进度
- 当前成员可以确认或取消确认
- 修改公约后应在正式版本中要求成员重新确认

公约不是单方面规定，而是所有室友共同选择的生活边界。

## 关键产品亮点

### 从“管理事务”升级为“维护关系”

普通合租工具通常只解决记账或排班问题。FamilyNow 在此基础上加入匿名留言、感谢表达和公约共识，让产品同时关注事务效率与室友关系。

### 行动优先的首页

首页不堆积复杂报表，而是优先回答三个问题：

- 我现在需要做什么？
- 有什么事情需要大家关注？
- 当前账目和共同生活是否正常？

### 低学习成本

核心操作都可以在少量步骤内完成：

- 记账时只需填写费用并选择参与人
- 值日任务可以直接标记完成
- 库存通过加减按钮快速更新
- 留言可直接选择公开或匿名
- 公约状态一键确认

### 面向手机场景

合租事务通常发生在采购、缴费、打扫等即时场景中，因此产品采用移动端优先的响应式布局，同时兼容桌面浏览器。

## Demo 使用说明

建议按照以下流程体验：

1. 在“家的此刻”查看合租屋整体状态。
2. 点击“记一笔费用”，新增一笔共同支出并观察余额变化。
3. 进入“清洁值日”，标记厨房清洁任务完成。
4. 进入“公共物品”，调整物品数量并查看补货状态。
5. 进入“暖心留言”，分别尝试公开和匿名留言。
6. 对留言点击“温暖”或“收到”。
7. 进入“室友公约”，确认尚未确认的公约。
8. 如需重新演示，可点击桌面端左下角的“恢复初始数据”。

## 当前技术方案

首版采用单文件 Web Demo：

- HTML：页面结构与语义内容
- CSS：响应式布局、视觉系统和交互状态
- JavaScript：费用计算、状态更新和用户操作
- localStorage：在当前浏览器保存演示数据
- 无第三方运行依赖，可直接通过浏览器打开

选择单文件方案的原因：

- 能在限时场景中快速形成完整、可操作的产品闭环
- 不依赖服务端、数据库或第三方登录
- 避免评审者被注册、验证码和权限配置阻塞
- 易于部署到任意静态托管平台
- 后续可以在保持界面结构的前提下替换为真实数据服务

## 数据与隐私说明

- 当前版本使用虚构成员和演示数据。
- 数据只保存在当前浏览器的 localStorage 中。
- 不会上传账单、留言或成员信息。
- 不同设备之间暂时不会同步。
- 清除浏览器数据后，用户新增的内容会消失。
- 匿名留言在当前 Demo 中属于界面级匿名；正式多人版本需在服务端隐藏作者身份，并严格限制管理员查询权限。

## 设计方向

视觉概念为“现代家庭公告板”：

- 深蓝色代表可靠、秩序和共同空间
- 黄色与珊瑚色提供温暖、年轻的生活感
- 留言采用纸条式视觉语言，强化家庭留言板的联想
- 卡片和圆角降低传统管理工具的严肃感
- 关键信息保持高对比度，兼顾手机阅读和操作

## 当前版本边界

本版本定位为产品交互 Demo，目前不包含：

- 真实账号注册与登录
- 多个合租屋管理
- 多设备实时同步
- 服务端匿名身份保护
- 真实短信、微信或系统推送
- 在线支付和自动转账
- 文件或账单图片上传
- 公约版本历史和管理员权限

这些能力不会影响评审者体验核心产品结构和主要操作流程。

## 后续迭代计划

### 第一优先级：完成真实协作闭环

- 接入数据库，实现跨设备同步
- 增加合租屋、成员邀请和角色权限
- 为不同合租屋实施严格的数据隔离
- 保存账单、排班、库存、公约和留言历史

### 第二优先级：增强核心模块

- 支持按比例、自定义金额和部分成员分摊
- 增加已结算状态和历史结算记录
- 支持周期值日、自动轮换和换班
- 将补货采购一键转换为 AA 费用
- 增加公约版本、提案和重新确认机制

### 第三优先级：提升沟通体验

- 为匿名留言增加内容安全与反滥用规则
- 提供更温和的表达建议
- 增加仅表达者可见的留言状态
- 允许室友用“已看到”“愿意帮忙”等低压力方式回应
- 对敏感问题提供非暴力沟通句式提示

### 第四优先级：智能化能力

- 通过自然语言快速记账
- 从购物小票识别金额和公共物品
- 根据成员时间自动生成公平排班
- 自动汇总每月合租报告
- 将带有情绪的原始表达转换为更中立、友善的留言建议

## 正式版本安全要求

- 金额使用最小货币单位存储，避免浮点精度问题。
- 所有输入在保存和展示前进行校验与转义。
- 合租屋数据必须按成员身份进行权限隔离。
- 数据库管理员密钥不得出现在浏览器端。
- 匿名留言不得在普通界面或接口响应中泄露作者。
- 删除账单、公约和成员等重要操作需要确认或撤销能力。
- 成员搬离后保留历史记录，但不能继续参与新排班和新账单。
